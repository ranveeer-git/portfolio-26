# Portfolio requirements

- Use specific, factual copy from the supplied resume or verified projects. Never invent metrics, reviews, customers, testimonials, qualifications, or availability.
- Do not use purple gradients, pill-shaped buttons, emoji icons, em dashes, vague hero slogans, AI-generated photos, custom cursors, cursor effects, or scroll animations.
- Use the supplied real portrait, solid colors, readable typography, and simple controls.
- Do not add Made with AI branding.
- Preserve the favicon and linked privacy policy and terms pages.
- Deployment is on hold until a custom domain is purchased, connected, and verified. Do not push to main during this hold because GitHub Pages automatically deploys those pushes. Do not unpublish the existing site unless requested.
- Preserve EmailJS. Send a test message only when the user authorizes that test.
